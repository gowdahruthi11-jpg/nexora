Three checks, one honest score

No single signal proves tampering on its own — so Verity runs all three and only flags a file when the evidence adds up.

Step 1

Fingerprint it

A SHA-256 hash is generated the moment a file is uploaded — a unique signature that changes completely if even one pixel is altered later.

Step 2

Read the metadata

Hidden EXIF and document fields are inspected for editing-software signatures and mismatched creation vs. modification dates.

Step 3

Scan the pixels

Error Level Analysis re-compresses the image and compares it to the original — localized edits light up as compression outliers.
